Introduction to API

Learn how to integrate our enterprise services into your application.

Overview

API provides a unified managed platform to access verified third-party APIs. Instead of managing dozens of vendors, you integrate with our gateway, and we handle the routing, SLA, and consolidated billing.

Authentication

All API requests must be authenticated using Bearer tokens. Include your Secret Key in the Authorization header of your HTTP request.

Authorization: Bearer sk_live_your_secret_key

Base URL

Use the following base URL for all production API requests:

https://api.apicoast.com/v1

Demo Code Example (Node.js)

Here is a quick example of calling the OTP service endpoint.

const axios = require('axios'); async function sendOTP(phone) { try { const response = await axios.post('https://api.apicoast.com/v1/communication/otp', { phone: phone }, { headers: { 'Authorization': 'Bearer ' + process.env.API_COAST_SECRET_KEY, 'Content-Type': 'application/json' } }); console.log(response.data); } catch (error) { console.error(error.response.data); } }

Note: These endpoints and credentials are examples until real backend endpoints are connected.
